# scene/entities/icons

The icons of the entity catalog: one file per entity (`network`, `device`, `firewall`, `edge`, `internet`, `actor`, `packet`, `stamp`), each exporting the icon of its entity, and `entity-icon.tsx`, which draws the icon of any `EntityRef`. `ink-icon.tsx` is `InkIcon`, the 24×24 frame every icon is built in, which `src/ui/card-icon.tsx` also uses for the icons of the cards. The design of every entity (its card: concept, shape, variants, states, label, movement and accessibility) is in `docs/specs/2026-10-09-follow-the-packet-chapter-1-design.md`, section "Catálogo de entidades".

- A network is drawn as its slab (`office`, `vpc`) or, for the `block` variant, as a dashed outline around the pieces the player placed inside a block of IPs. A device is drawn in the variant of its model (`laptop`, `printer`, `ec2-instance`) or as the server of the internet (`internet-server`), a narrow tower with three bays and an antenna stub, not the wide box with a lid and one door of the EC2 instance. It is a variant of the device piece, never a sibling entity.
- A packet is drawn by its protocol: ICMP is a dot, TCP a square and UDP a hexagon (`PACKET_SHAPES`), each filled when it asks and a ring when it answers, so an answered packet comes back as the ring of its own protocol. An intruder is the same shape with a second border of the same shape around it (the shape says the protocol and the border says the role, for every protocol); no packet is drawn as a rhombus. A warning (Destination Host Unreachable, Time Exceeded) is the `warning` variant of the same piece, a triangle with an exclamation mark, and is never an intruder's. A stamp has a shape of its own for each of its states.
- An icon is the piece seen from the front, in one colour (`currentColor`, drawn with `InkIcon`), hidden from screen readers because the text beside it names it. Every variant and every stamp state has its own shape, and a state is never shown by colour alone.
- The rest of the game reaches the icons through `@/scene` (`EntityIcon`, `StampIcon` and `InkIcon`); files inside import each other directly (`./x`).
- Not here: the pieces the map draws (`../`), where a piece sits (`../../map2d/layout/`), the packets in flight and their labels (`../../map2d/traffic/`), labels as buttons (`../../overlay/`).
- May import: `@/copy` and only types from `@/engine`.
