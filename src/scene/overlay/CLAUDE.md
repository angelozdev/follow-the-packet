# scene/overlay

HTML drawn on the map's HTML layer: piece labels as buttons, the name of each floor (`floor-label.tsx`, plain text in the caption style), the anchor that keeps a card beside its piece (`card-anchor.tsx`; `use-card-side.ts` picks the side, or the dock in the map's bottom left corner, from the placement of `layout.ts`, and the card's gap and width reach `.map-card` as the CSS variables `--card-gap` and `--card-width`; the dock offset reaches it as `--card-x` and `--card-y`, and the height a docked card may take as `--card-room` (`none` when nothing limits it), which the hook writes on the element in the same frame that drei moves the anchor, because a state would lag a frame and show the docked card displaced when the origin changes or the map pans; one `<Html>` always holds the card, so changing position never remounts it and its picks stay), and the shared hover-and-focus handlers.

- A label shows a text the game already made safe for the ladder; it never decides what a piece is or whether it can be changed. It shows the lock of a fixed piece and the alert «!» of a device under attack, both also read as text, so neither can cover another label. A piece may carry a second entry (`settings`, an id and a label): it is drawn as a second button under the label, in the same look, and activates its own id; it is not a piece, so it has no shape, no place and no inspection. A resource's own name in the label (`[[servidor2]]`) is drawn as a name tag (`NameTag` of `@/design`), apart from the entity; the label's look (`map-button`) is in the design system's stylesheet.
- Not here: the cards themselves and every other panel (`src/ui/incident/`, `src/ui/incident/map-cards/`), moving packets and stamps (`src/scene/traffic/`).
- May import: `@/copy`, `@/levels`, `@/design`, only types from `@/engine`, and other files of `src/scene/` (`@/scene/<file>`).
