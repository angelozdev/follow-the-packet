### T2 · Motor: la app contesta HTTP (01 y 02)
- **Contrato** (`src/engine/web/`, `src/engine/simulation/stages/web/` y lo que toque de `network/` y `simulation/`). `PacketSpec.message?` es la petición HTTP (`method`, `url`, `headers?`, `body?`), solo en TCP. `parseUrl` da esquema, nombre o IP, puerto (80 y 443 por defecto), path y query string, y descarta `#…`.
- `Service.web?` trae los sitios con sus páginas y el sitio por defecto, que se elige por la cabecera `Host`. Manejadores `fixed`, `order-read`, `order-create` y `order-replace`; path o método no admitido da 404; el POST que crea da 200.
- Etapa `app` tras `host`, solo si hay mensaje; `Trace.app {request, response?}`, ausente sin mensaje; `Carried.apps` lleva los pedidos (arrancan en 7 y 8). Respuestas con solo `Content-Type` y `Content-Length` (en bytes). Un servicio que acepta y no habla HTTP termina `arrived-no-reply`.
- **El motor no escribe frases:** los cuerpos, el del 404 incluido, llegan en los datos de la app que escribe el incidente. Motivos `web-site-chosen`, `web-default-site` y `web-answered`, con su frase en `src/copy/web/` para que compile `describeReason`.
- **Pruebas.** `a url without a port gets 80 for http and 443 for https` · `the fragment is dropped before the request is built` · `the request carries a Host header with the name of the url, and the port when it is not the default` · `the length of a body counts bytes, not characters` · `a packet with a message travels in a tcp connection that the greeting opened` · `the web stage writes no step for a packet with no message` · `the new trace fields are absent from every trace of a VPC` · `the reply of an http exchange is never stopped by a firewall, outbound or inbound` · `a message to a closed port ends refused and has no response` · `a message through a firewall that drops ends in timeout and has no response`.
- `a get of an order that exists answers 200 with its body` · `an order that does not exist answers 404` · `a path that is not served answers 404` · `a post creates the next order and a second post creates another` · `a put leaves the order as its body says and a second put leaves it the same` · `the orders are carried from one send to the next` · `the site is chosen by the host header and not by the ip` · `a name with no site gets the default site` · `a name that went through a cname travels in host as the url wrote it`. - **Riesgos.** Un motivo nuevo deja sin compilar los `switch` de `describeReason` y de `hiddenCause`: se completan, sin tocar ninguna traza. `Carried` gana un campo y se arma en varios literales (`NOTHING_CARRIED`, `emptyState`, `sendQuestion`, `conclude`). ## Riesgos
