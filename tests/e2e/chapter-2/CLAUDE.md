# tests/e2e/chapter-2

The end-to-end tests of chapter 2 (the fourteen incidents 02-01 to 02-14).

- `chapter-2-play.ts` says how each incident is played with the mouse: `CHAPTER_2`, a list of `PlayedIncident` (`id`, `title`, `play`) in game order, with the incidents built so far (02-01 to 02-09). `LAST_BUILT_OF_CHAPTER_2` is the id of the last one, which opens 04-01 until 02-14 exists, so the specs that open 04-01 read it and a content task that adds an incident moves them with the list. Each content task (23 to 33 of the plan) adds the incident it builds and, with it, a smoke test of its block; the whole-chapter test (task 34) plays the list from 02-01 to 02-14, each incident opening the next with three stars. `PlayedIncident` is the type of chapter 1 (`@e2e/chapter-1/chapter-1-play`): the shape of a played incident is the same in every chapter.
- The shared helpers (`cards`, `closing`, `console-errors`, `map-boxes`, `saved-progress`) stay in `tests/e2e/` and are imported through the alias `@e2e/` (`@e2e/cards`), never with `../`. The progress that opens a chapter with the ones before it done is in `@e2e/saved-progress` (`CHAPTER_1_DONE`, `CHAPTER_2_DONE`).
